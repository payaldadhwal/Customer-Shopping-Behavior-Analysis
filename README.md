# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior using SQL, Python (Pandas), and Power BI. The goal is to extract meaningful insights from the data and present them through an interactive dashboard to support data-driven decision-making.

## 📂 Dataset

* The dataset is provided in CSV format.
* It contains comprehensive information about customer shopping behavior, including demographic details, purchasing patterns, product categories, and customer feedback.
* The data includes multiple attributes that help analyze customer segmentation, spending habits, and overall business performance.

## 🛠️ Tools & Technologies Used

* **SQL** – Data cleaning and querying
* **Python (Pandas)** – Data preprocessing and analysis
* **Power BI** – Data visualization and dashboard creation
* **CSV Files** – Raw dataset

## 🔄 Project Workflow

1. Collected the raw dataset in CSV format
2. Loaded the data into Python using Pandas for analysis
3. Performed data cleaning:

   * Handled missing values
   * Checked for inconsistencies
   * Renamed columns for better readability
4. Conducted exploratory data analysis (EDA) to understand customer behavior patterns
5. Wrote SQL queries to extract insights and perform structured data analysis
6. Built an interactive dashboard in Power BI to visualize key metrics and trends


## 📊 Dashboard

The Power BI dashboard provides an interactive view of customer behavior using key performance indicators (KPIs), including:

* Average Purchase Amount

## 🔍 Key Insights

* The total customer base consists of approximately **3.9K customers**, indicating a moderately sized dataset with diverse customer segments.

* The **average purchase amount is $59.76**, suggesting that most customers fall into a mid-range spending category, creating opportunities for upselling and bundle offers.

* The **average review rating of 3.75** indicates generally positive customer satisfaction, but also highlights scope for improving product quality or service experience.

* A significant **73% of customers are non-subscribers**, while only 27% are subscribed, indicating a strong opportunity to increase revenue through subscription-based marketing strategies.

* **Clothing is the top-performing category**:

  * Highest number of customers (~1.7K)
  * Highest revenue (~104K)
    This suggests clothing is the primary driver of business growth.

* **Accessories and Footwear** contribute moderately to revenue, while **Outerwear shows the lowest performance**, indicating potential underperformance or lower demand.

* **Young Adults generate the highest revenue and sales**, making them the most valuable customer segment.

* **Middle-aged customers** also contribute significantly, indicating a secondary target segment.

* **Senior and Adult segments** show relatively lower engagement, suggesting an opportunity for targeted marketing campaigns.

* Customer behavior varies significantly across categories and age groups, highlighting the importance of **segmented marketing and personalized recommendations**.
